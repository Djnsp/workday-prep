# Workday Certification Prep

Three single-file study apps (HCM Core, Extend, Integrations) plus a launcher,
hosted as a static site. Works offline after first load; installable on iPhone
via Safari > Share > Add to Home Screen.

Original practice content for personal study — not official Workday material.

## Updating an app
Replace the relevant .html file, then bump the version in sw.js
("wdprep-v1" -> "wdprep-v2") so devices fetch the new copy.
